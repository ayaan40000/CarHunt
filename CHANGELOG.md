## 2026-11-18 — Trait icons, database layer, slim entrance, negotiation notes, representative images

Feature build on the Nov 18 board (same 47 listings, same grades/prices; one data correction noted below).

- **Clickable trait icons on every card.** A chips row on the card face: body type (sedan/SUV glyph + label), hybrid (leaf, only where `hybrid` is confirmed true), seller (private/dealer), grade (star + exact grade), reliability (shield + score). Clicking a chip filters the board to that trait; traits combine (AND) with all existing filters; clicking an active chip clears it; active state shows on the chips and in the filters panel + badge count. The panel gains Seller, Grade band and Min reliability controls and a Clear-all button. One hybrid is confirmed on the board (2019 Ford Fusion SEL) — see the data note below.
- **Database layer.** `data/carhunt.db` (SQLite, stdlib) is now the canonical working store, managed by `tools/carhunt_db.py`: board records stored verbatim with extracted trait columns, plus 127 staging rows imported from the goal workspace. `data/listings.json` is an export of the DB in the exact canonical format; the import→export round trip is verified deep-equal and byte-identical (`carhunt_db.py verify` — a publish gate from now on). The DB itself stays local (the push route is text-only); the repo carries the exported JSON and the tool.
- **Slim entrance.** The header is now logo + name + a one-line board summary, and the data stamp renders as one line — visible above-the-fold prose drops from 1,572 to 203 characters (−87%), and listings start immediately. Nothing was deleted: the criteria and honest-headline paragraphs and the full run notes (including the CarMax disclosure) moved verbatim into the FAQ & Help tab ("About this board" / "Run notes — Nov 18, 2026").
- **Negotiation notes per listing.** New append-only field `negotiation_notes` on all 47 records, rendered in each card's details under "Negotiation": 2–4 pointers from the car's own evidence — the asking-vs-estimate gap in dollars, listing age and price drops, dealer out-the-door/doc-fee framing vs private-seller flexibility, and the car's own blockers (title proof, camera-recall remedy, piston-program proof, IVT test-drive condition) as document asks. Cars already far under estimate say so honestly: move fast, verify paperwork, don't invent leverage.
- **Representative images + Visual tab.** New append-only fields `representative_image` / `representative_image_source` on all 47 records: one hotlinked Wikimedia Commons photo per year/make/model generation (11 groups; e.g. 2016–18 vs 2019+ Malibu shown as their own generations), every URL downloaded and visually verified before shipping. Cards label it "Representative image — not the actual car"; it is strictly separate from `photo_urls`. A new Visual tab groups the board by model with the image prominent and a "Show in Listings" shortcut per group. No image binaries are committed.
- **Hybrid data correction.** Auditing all 47 records against their listing evidence: the 2020 Ford Fusion with unstated trim/engine had `hybrid: false` with no evidence either way — corrected to `null` (unproven is not false; its pref score and C+ grade are unaffected). All other records' hybrid values are supported by their evidence. True hybrid count before and after the audit: **1** (the 2019 Fusion SEL Hybrid).
